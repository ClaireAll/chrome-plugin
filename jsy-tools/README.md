# jsy-tools

九数云 Chrome 扩展。所有功能默认关闭，可在配置页逐项开启。设置自动保存，并同步到已打开的适用页面。

## 安装与启用

在 Chrome 111 或更高版本中打开 `chrome://extensions`，开启「开发者模式」，选择「加载已解压的扩展程序」并选中 `jsy-tools` 目录。点击插件图标打开配置页。项目功能适用于 HTTP 或 HTTPS 下的 `/decision/home/project/项目标识` 及其子页面，支持自定义域名和端口。重新加载扩展后，请刷新已打开的九数云页面。

## 分类汇总批量设置

打开分析表的「分类汇总」步骤，点击「合并上一步数据」左侧的「批量设置」。可以直接勾选右侧汇总胶囊，也可以在左侧选择来源字段：进入批量模式时会带入已有选择，之后增选或取消一个来源字段，会同步到它对应的所有已有汇总项。在「统一汇总方式」中选择一种共同支持的方式即可立即应用。「第一项」和「最后一项」默认按各自来源字段升序取值。

要批量调整组内排序，勾选当前步骤里使用「第一项」「最后一项」或「拼接」的汇总项，点击「设置排序」打开九数云原生排序弹窗。可以添加多个排序字段，从上到下指定优先级和升降序。支持自定义排序的字段可以从「待排序值」中选择现有值、补充新值并拖动调整顺序。弹窗点「确定」后，在工具栏点「应用到 N 项」，统一写入所选项的排序规则并退出批量模式。移除全部排序规则后再应用可清除所选项的排序。分析表沿用原有保存流程。

## 快捷上传 Excel

将一个或多个 `.xlsx`、`.xls` 或 `.xlsm` 文件拖入项目页面，插件会依次导入每个文件的第一个工作表，以首行为表头，并将新表添加到当前项目根目录。导入在后台执行，期间请保持页面打开。若源表已保存但未出现在项目中，可从「Excel 管理」继续添加；再次拖入同一文件会新建另一张表。

## 最近操作快捷栏

在分析表中通过「＋」菜单或快捷按钮执行操作后，该操作会出现在顶部左侧，最近使用的排在最前。相同操作只保留一项，工具栏按可用宽度展示完整按钮。记录保存在插件本地，同一浏览器配置下的项目和标签页共用，重启后保留。关闭功能会恢复原工具栏。

## 表数据预览

启用后，左侧项目栏底部会出现「表数据预览」开关，当前项目的预览初始为开启。配置步骤时可暂时关闭预览，后续预览请求会返回表头和空数据，步骤仍可编辑和保存。重新开启时，只补发当前项目最后一个被拦截的请求；该请求可能来自之前查看的表或步骤。刷新页面后恢复开启，缓存随之清空。

## 表格样式

在配置页为分析表编辑页下方的数据预览表格选择简洁、斑马纹或网格样式，调整主题色，并从小、中、大三档字号（12、14、16 px）中选择。配置页可实时预览效果，所有项目共用这套设置。关闭功能后恢复原样式，并保留已选配色和字号。

## 企业快捷搜索

打开「切换企业」，在标题下方输入名称即可模糊筛选，英文忽略大小写。最近使用的企业优先排在各自原分组内；使用记录由同一浏览器配置下的账号共用，每个账号只看到自身列表中的企业。也支持 `jdydevelop.com` 及其子域名的 `/dashboard#/` 页面，同时筛选「我创建的」和「我加入的」企业或团队，并隐藏无匹配结果的分组。

## 快捷创建副本

在项目左侧选中表、FVS、故事板或指标树，按 `Ctrl+C` 后再按 `Ctrl+V`。插件会复制该资源已保存的内容，以「原名称_时间戳」命名，并将副本排在同一分组的原资源下方。复制记录仅在当前页面有效。若提示副本已创建但排序失败，请先刷新列表查看，避免重复创建。

## 标签页快捷关闭

在项目顶部右键点击要保留的资源标签。「关闭其它标签页（强行）」会直接丢弃其它标签的未保存修改并关闭它们；「关闭其他已保存标签页」仅关闭没有待保存修改的其它标签。只有一个资源标签时，右键不会显示此菜单。

## 自动化内嵌显示

点击项目原有的「自动化」入口，编辑器会显示在右侧内容区，顶部资源标签和左侧项目列表仍可使用。切换到其它资源后，再次点击「自动化」可继续编辑。切换资源不会自动保存，保存和执行仍使用产品原有入口。

## 快捷开启跨项目引用

在「添加数据」弹窗的「当前空间」中，悬浮到尚未开启跨项目引用的来源表上。有权限时，行右侧会显示「开启跨项目引用」。点击后立即提交，成功后可手动勾选该表。

## 步骤快捷删除

悬浮在分析步骤上，点击右上角的红色 × 可直接删除该步骤，无需二次确认。点击「来源表」上的 × 会删除全部后续分析步骤，保留来源表和图表。开启此功能下的「是否改为快捷应用」后，普通步骤改为显示橙色 − 或绿色 √，分别用于取消应用和重新应用；此模式下「来源表」隐藏悬浮按钮。

## 项目快速切换

点击项目页左上角当前项目名称左侧的下拉箭头，可从最近打开的项目中直接切换。列表沿用首页中当前账号、当前企业的最近项目及其顺序，并标出当前项目。
