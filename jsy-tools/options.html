按宽度显示

表数据预览

配置分析步骤时，可暂时关闭表数据预览，减少反复加载数据的等待；重新开启后，加载最后一次预览请求的数据。

已关闭
项目级生效插件能力默认关闭
使用说明
项目开关
左侧项目栏底部显示开关，控制当前项目内所有分析表的数据预览。设置页开关只控制此能力是否启用。
关闭预览
后续 page 请求直接返回空数据，保留字段表头，不影响步骤配置和保存；已经发出的请求不会取消。
重新开启
仅补发最后一个被拦截的请求，对应的表和步骤不一定是当前可见页面；没有缓存时不补发。
项目预览状态
开启插件能力后，项目预览状态和请求缓存仅留在当前页面内存中，刷新或重新打开后恢复开启。停用此能力后恢复正常请求并清除缓存。

企业快捷搜索

快速搜索企业，最近使用的企业优先显示，减少翻找。

已关闭
输入即筛选最近使用优先所有账号共用
使用说明
搜索企业
打开“切换企业”弹窗，在标题下方输入企业名称即可模糊筛选，忽略英文大小写。搜索框固定，仅企业列表滚动。
最近使用
根据列表确认的“当前所在企业”记录使用顺序，在原列表各分组内优先显示最近使用的企业，不新增分组。搜索结果沿用最近顺序，未使用过的企业保持原有相对顺序。记录保存在插件本地，所有账号共用，刷新和重启后保留。
清空搜索
点击清空按钮，或有搜索内容时按 Esc，可恢复完整列表；重新打开弹窗后清空搜索内容。
简道云适配
支持 jdydevelop.com 及其子域名下的 /dashboard#/ 页面。同时搜索“我创建的”和“我加入的”企业/团队，无匹配结果的分组标题和列表整体隐藏，保留加入、创建按钮。
按需关闭
默认关闭，设置自动保存；关闭后移除搜索框，恢复完整企业列表及原顺序，停止记录最近企业，已有记录保留。不改变企业切换和创建流程。

快捷创建副本

使用 Ctrl+C / Ctrl+V，在当前项目的原资源下方创建副本。

已关闭
表 / FVS / 故事板 / 指标树单个复制当前项目内
使用说明
快捷操作
先点击左侧资源，按 Ctrl+C 复制，再按 Ctrl+V 创建副本；每次仅复制一个，不能跨项目粘贴。
创建结果
自动命名为“原名称_时间戳”，重名时追加序号。副本插入同一分组的原资源下方并保存排序；停留在原资源，更新列表并提示成功。
文字编辑
从左侧资源复制后，点击画布仍可按 Ctrl+V 创建副本。输入框、公式编辑器和文字选区仍使用正常的复制粘贴。
复制内容
复制服务端已保存的资源，未保存的编辑不会包含。沿用当前登录态和服务端权限校验；创建过程中重复按键不会重复提交。
页面状态
复制记录只留在当前页面内存中，刷新、切换窗口或复制其他文字后清空；不保存资源内容。默认关闭，关闭后恢复原有快捷键行为，已创建的副本保留。

标签页快捷关闭

右键项目资源标签，快速关闭其它标签页。
强行关闭会直接丢弃其它标签的未保存修改，不再确认。

已关闭

关闭其它标签页（强行） · 关闭其他已保存标签页

标签右键保留目标标签
使用说明
右键入口
在当前项目顶部资源标签上右键，以右键点击的标签为保留目标，包含溢出未显示的其它资源标签。
强行关闭
直接丢弃其它标签的未保存修改并关闭，不弹确认；保留目标标签及其修改，不删除项目资源。
只关已保存
直接关闭其它没有未保存修改的标签，保留目标标签和所有未保存的标签。
按需关闭
默认关闭，设置自动保存；关闭此能力后恢复原有右键行为，不影响标签的点击、编辑和原生关闭按钮。

已关闭

使用说明
显示位置

原生操作

按需关闭
默认关闭，设置自动保存；关闭后移除内嵌布局，恢复产品原有展示方式。不支持的页面结构会在控制台说明，不强行移动编辑器。
